САЙТ ДЛЯ АЙЫМЫ ♡ — белый и нежно-розовый стиль

ОТКРЫТЬ:
1. Распакуй ZIP.
2. Открой index.html в браузере.

МУЗЫКА:
Нажми «Добавить музыку» и выбери аудиофайл на компьютере (например MP3).
Автозапуск часто блокируется браузером, поэтому используется кнопка.

ФОТО:
Нажми «Добавить наши фото» и выбери снимки. Это предварительный просмотр только в текущем браузере.
Чтобы фото и музыка были доступны Айыме по ссылке, их нужно добавить в папку сайта и опубликовать весь сайт в интернете.

ПУБЛИКАЦИЯ:
Сайт пока лежит на твоём компьютере. Для общей ссылки его нужно загрузить на хостинг, например Netlify или GitHub Pages.
